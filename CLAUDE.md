# CLAUDE.md

This bundle's build contract is `spec/AGENTS.md` — read it before making any
change here.

**For any change beyond the initial staged build (however it was run — `/planout`,
`build.sh`, or the VS Code task):** write a plan into `plan/`
first (one markdown file per change), then execute it against `/app/`.

Do not edit `/app/` for an out-of-band change until the plan file exists under `plan/`.

See `spec/AGENTS.md` → *Further changes* for the full workflow.
