1.  components
1.1Overview

The Global Navigation Header is a persistent, fixed-position bar that appears at the top of every page within the Consent IQ platform. It serves two primary purposes: establishing brand identity and providing users with quick access to their personal account information and notification status.

1.2Step-by-Step Flow
1.Initialization: When the application loads, the system automatically requests the current user's information, including their name, assigned role, and any pending notifications.
2.Brand Display: The left side of the header displays the platform branding, including the "Consent IQ" title, a descriptive subtitle, and the "Powered by Agilisium" attribution.
3.Notification Check: The system checks for unread tasks. If any exist, a notification bell icon appears with a badge indicating the specific number of pending items.
4.User Identity Display: The right side of the header displays the user's profile information, including an avatar based on their initials, their full name, and their current role. If the system cannot retrieve specific user data, it defaults to generic placeholders to ensure the interface remains clean and functional.
5.Interaction: A dropdown menu icon (chevron) is provided next to the user profile to allow for future expansion of account-related actions.
1.3Key Concepts
–User Context: The collection of personal details (name, role, and notification count) that the system retrieves to personalize the header for each logged-in user.
–Fallback Logic: A safety mechanism that ensures the header displays default text (such as "User Name" or "ICF Author") if the system is unable to retrieve live data, preventing empty or broken-looking fields.
–Persistent Header: A design element that remains fixed at the top of the screen as the user navigates through different parts of the application, ensuring consistent access to navigation and status updates.
–Notification Badge: A visual indicator attached to the notification icon that dynamically updates to show the number of unread items, helping users stay informed about pending tasks.
1.4Business Value

This feature provides a professional and consistent user experience across the entire Consent IQ platform. By centralizing branding and user-specific information, it reinforces the platform's identity while allowing users to immediately gauge their workload through the notification badge. The use of automated data loading and fallback defaults ensures that the interface remains reliable and user-friendly, even if there are temporary issues with data retrieval.

2.  Data
2.1Overview

The Global Navigation Header is a consistent top-bar component designed to provide users with immediate access to their identity and status within the platform. It ensures that regardless of which page a user is on, they can see their name, professional role, and a summary of their current workload. The system is designed to be resilient, providing sensible default information if a user's profile data is temporarily unavailable.

2.2Step-by-Step Flow
1.The system identifies the currently logged-in user based on their active session.
2.The system retrieves the user's profile details, including their name, primary and secondary roles, and the number of tasks currently assigned to them.
3.If the system successfully finds the user, it displays their specific information in the header.
4.If the system cannot find the user (or if data is missing), it automatically displays a default profile: "User Name" with a role of "ICF Author" and zero tasks.
5.The header displays this information alongside a dropdown menu icon, allowing the user to interact with their profile settings.
2.3Key Concepts
–User Context: The collection of personal details (name, roles, and task volume) that the system uses to personalize the navigation experience.
–Resilience (Fallback Logic): A safety mechanism that ensures the navigation header remains functional and professional even if the system encounters an error or cannot retrieve specific user data.
–Task Summary: A quick-reference indicator that shows the user how many items currently require their attention.
2.4Business Value
–Improved User Experience: By providing a consistent header across the platform, users always know who is logged in and can easily access their profile.
–Operational Efficiency: Displaying task counts directly in the header helps users stay informed about their workload without needing to navigate to a separate dashboard.
–System Reliability: The fallback mechanism ensures that the interface remains clean and usable even during unexpected data issues, preventing broken layouts or confusing empty states for the end user.
