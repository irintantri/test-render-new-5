1.  Frontend
1.1Overview

The ICF Creation Setup page is a three-column wizard designed to prepare the necessary information for the AI to generate an Informed Consent Form (ICF). Users walk through a structured process to identify the clinical study, provide supporting documentation, and select the appropriate document format.

1.2Step-by-Step Flow
1.Select Protocol: The user begins by choosing a clinical protocol from a list. A search bar is available to filter protocols by name or ID. Once a protocol is selected, it is highlighted to confirm the choice.
2.Attach Reference Documents: The user provides context for the AI by attaching an "Investigation Brochure" and a "Lab Manual." These can be uploaded directly from the user's device or fetched from the document management system.
3.Select Template: The user chooses a document template to define the structure of the final ICF. A "standard" template is selected by default, and the system highlights any templates recommended for the chosen protocol.
4.Validation: The system ensures a protocol is selected before allowing document uploads. If any errors occur (such as a failed upload or missing selection), an error banner will appear to guide the user.
1.3Key Concepts
–Protocol: The specific clinical study or trial for which the ICF is being generated.
–Reference Documents: Supporting files (like brochures or manuals) that provide the AI with the necessary background information to draft accurate content.
–Template: A pre-defined document structure that ensures the generated ICF meets specific formatting and regulatory requirements.
–Client-side Filtering: A feature that allows the user to instantly narrow down the list of protocols as they type, without needing to reload the page.
1.4Business Value

This feature streamlines the ICF creation process by centralizing all required inputs into a single, intuitive interface. By requiring users to link specific reference documents to a protocol and select a standardized template, the system ensures that the AI has high-quality, relevant data to work with. This reduces manual effort, minimizes the risk of using incorrect study information, and ensures consistency across all generated consent forms.

2.  Logic
2.1Overview

The ICF (Informed Consent Form) Creation wizard is a three-step interface designed to help users prepare the necessary information for AI-assisted document generation. By guiding the user through selecting a clinical protocol, attaching relevant reference materials, and choosing a document template, the system ensures that the AI has the correct context to produce accurate and compliant documentation.

2.2Step-by-Step Flow
1.Protocol Selection: Upon opening the wizard, the system displays a list of available clinical protocols. Users can browse the full list or use the search bar to find a specific protocol by name or ID.
2.Reference Document Attachment: Once a protocol is selected, the user provides the necessary reference materials (such as an Investigator’s Brochure or Lab Manual). Users have two options for each document type:

* Upload: Directly upload a file from their local device.

* Fetch from DMS: Retrieve existing documents already stored in the Document Management System (DMS) associated with the selected protocol.

3.Template Selection: The user selects a document template from a provided catalog. The system highlights recommended templates to assist the user in making the best choice for their specific needs.
4.Validation: Throughout the process, the system ensures that a protocol is selected before allowing document retrieval, providing clear feedback if a step is missed or if an upload fails.
2.3Key Concepts
–Protocol: The specific clinical study or trial framework that serves as the foundation for the document being generated.
–Reference Documents: Supporting files (like manuals or brochures) that provide the AI with the necessary background information to generate accurate content.
–DMS (Document Management System): A centralized repository where existing project documents are stored and can be retrieved for use in the wizard.
–Template: A pre-defined document structure or "blueprint" that dictates the format and style of the final generated ICF.
2.4Business Value
–Efficiency: By centralizing protocol selection, document retrieval, and template choice into a single wizard, the time required to prepare for document generation is significantly reduced.
–Accuracy: Providing the AI with specific, verified reference documents ensures that the generated ICF is contextually relevant and aligned with the correct clinical protocol.
–Consistency: Using standardized templates ensures that all generated ICFs maintain a professional, uniform structure, reducing the risk of manual formatting errors and improving compliance.
3.  Data
3.1Overview

The ICF (Informed Consent Form) Creation Setup feature is a guided, three-step wizard designed to streamline the preparation of new consent documents. By centralizing the selection of clinical protocols, reference materials, and document templates, the system ensures that users have all the necessary components ready before triggering the AI-driven generation process.

3.2Step-by-Step Flow
1.Protocol Selection: Upon opening the wizard, the system displays a catalog of available clinical protocols. Users can browse the full list or use a search function to quickly find a specific protocol by its name or ID.
2.Reference Document Attachment: Once a protocol is selected, the user can view or upload relevant reference documents. The system retrieves existing documents associated with that specific protocol and allows for the addition of new files, ensuring all source material is linked correctly.
3.Template Selection: The user chooses an appropriate document template from a curated list. The system highlights "recommended" templates to help users select the most suitable format for their specific needs.
4.Launch Generation: With the protocol, reference documents, and template confirmed, the setup is complete, and the user can proceed to launch the AI generation process.
3.3Key Concepts
–Protocol: The foundational clinical study framework that dictates the requirements for the consent form.
–Reference Document: Supporting files (such as study summaries or safety information) that provide the necessary context for the AI to generate an accurate consent form.
–Template: A pre-defined document structure that serves as the starting point for the AI, ensuring consistency and compliance across different consent forms.
–Wizard: A user-friendly interface that breaks a complex task into manageable, sequential steps to prevent errors and improve efficiency.
3.4Business Value
–Efficiency: Reduces the time spent manually gathering study information and formatting documents by automating the setup phase.
–Consistency: By using standardized templates and linking specific reference documents to protocols, the organization ensures that all generated consent forms meet internal quality and compliance standards.
–User Experience: The guided wizard approach minimizes the learning curve for new users and reduces the likelihood of missing critical information during the document preparation stage.
