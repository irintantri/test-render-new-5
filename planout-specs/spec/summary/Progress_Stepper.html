1.  Components
1.1Overview

The Progress Stepper is a visual navigation tool displayed at the top of the creation screens in the BeOne platform. It provides users with a clear roadmap of the five-stage creation process, helping them understand their current progress and allowing them to jump back to previous stages if needed.

1.2Step-by-Step Flow
1.Display: The system renders a horizontal bar showing five distinct stages: Setup, Generate, Edit & Refine, Review, and Preview.
2.Status Identification: Each step is automatically assigned a status based on the user's progress:

* Done: Steps already completed (marked with a check icon).

* Active: The current step the user is working on (highlighted for visibility).

* Future: Steps that have not yet been reached (grayed out).

3.Navigation: Users can click on any "Done" or "Active" step to return to that screen, provided the following safety rules are met:

* The "Generate" step is a temporary process and cannot be clicked.

* Advanced steps (Edit, Review, and Preview) can only be accessed if a document has been successfully created.

1.3Key Concepts
–Step Status: A visual indicator that tells the user whether a stage is finished, currently in progress, or upcoming.
–Transient Step: A specific stage in the process that acts as a bridge or background task; because it is not a static page, users cannot navigate back to it directly.
–Conditional Navigation: A security feature that ensures users can only access later stages of the process once the necessary data (the document) has been generated.
1.4Business Value

The Progress Stepper improves the user experience by reducing confusion during complex workflows. By clearly showing the path ahead and allowing users to easily revisit previous steps, it minimizes errors and helps users feel in control of the creation process. This modular design also ensures that users cannot skip essential steps or access advanced features before the system is ready to support them.
