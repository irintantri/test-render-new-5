1.  COMPONENTS
1.1Overview

The "Generate" page features a fixed navigation bar at the bottom of the screen designed to give users control over their workflow. This bar provides two clear options that allow users to either return to the initial configuration phase or bypass the current generation process entirely to move directly to manual editing.

1.2Step-by-Step Flow
1.The user is presented with two action buttons at the bottom of the "Generate" page.
2.If the user selects "Back to Setup," the system navigates them away from the current page and returns them to the initial configuration screen.
3.If the user selects "Skip," the system bypasses the generation process and takes the user directly to the manual editing screen for their specific project.
1.3Key Concepts
–Back to Setup: A navigation option that allows users to restart or adjust their initial project settings.
–Skip: A navigation option that allows users to bypass the automated generation step and proceed immediately to manual refinements.
–Job ID: A unique identifier that ensures the system remembers which project the user is working on when they choose to skip ahead.
1.4Business Value

This feature improves user experience by providing flexibility and control. By allowing users to easily return to previous steps or skip unnecessary generation tasks, the interface reduces frustration and helps users reach their desired editing environment more efficiently. It ensures that the workflow remains non-linear, accommodating different user needs and project requirements.
