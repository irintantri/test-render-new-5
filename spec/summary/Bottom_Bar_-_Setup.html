1.  COMPONENTS
1.1Overview

The Bottom Action Bar on the "Setup" page provides a consistent navigation and action area for users. It allows users to easily return to the main dashboard or initiate the ICF generation process once all necessary setup requirements have been met.

1.2Step-by-Step Flow
1.Validation: The system continuously monitors the setup form. The "Generate ICF" button remains inactive until a protocol is selected, at least one reference is attached, and a template is chosen.
2.Navigation: Users can click the "Back to Dashboard" button at any time to exit the setup process and return to the main dashboard.
3.Initiation: Once the form is valid, the "Generate ICF" button becomes active. Clicking this button triggers the generation process.
4.Transition: Upon a successful start to the generation process, the system automatically redirects the user to the progress visualization page to track the status of their document creation.
5.Error Handling: If the generation process fails, the system will display a notification to the user, allowing them to attempt the action again.
1.3Key Concepts
–Conditional Activation: A safety feature that ensures the "Generate" action is only available when the required information is complete, preventing errors.
–Navigation Controls: Dedicated buttons that provide clear paths for users to either move forward with their task or exit to the dashboard.
–Progress Tracking: A seamless transition from the setup phase to a dedicated view where users can monitor the real-time status of their document generation.
1.4Business Value

This feature streamlines the user experience by providing clear, context-aware actions. By enforcing form validation before allowing the generation process to start, it reduces the likelihood of errors and ensures that the system always has the necessary data to produce high-quality ICF drafts. The intuitive layout helps users navigate the setup process efficiently, minimizing friction and improving overall productivity.

2.  logic
2.1Overview

The "Generate ICF" feature, located in the bottom action bar of the Setup page, allows users to initiate the creation of an Informed Consent Form (ICF) draft. By selecting a protocol and a template, the system automatically extracts and structures the necessary information from your documents to prepare the draft for further processing.

2.2Step-by-Step Flow
1.Initiation: Once you have selected a protocol, attached the required references, and chosen a template, the "Generate ICF" button becomes active.
2.Request Submission: Clicking the button sends your request to the system to begin the generation process.
3.Job Creation: The system creates a new "Generation Job" to track the progress of your request and immediately confirms that the process has started.
4.Document Parsing: In the background, the system retrieves the relevant document, extracts the text, and organizes it into a structured format.
5.Downstream Processing: Once the document is successfully parsed, the structured data is automatically passed to the next stage of the pipeline to finalize the ICF draft.
2.3Key Concepts
–Generation Job: A tracking record created by the system to manage your request from start to finish, ensuring you know the current status of your document generation.
–Protocol: The specific clinical study or research framework that provides the source material for the ICF.
–Template: A pre-defined layout or structure that dictates how the final ICF document should be formatted.
–Parsing: The automated process of reading a raw document and identifying its individual sections and data points so the system can use that information to build the new form.
2.4Business Value

This feature streamlines the document creation process by removing the need for manual data entry. By automating the extraction and structuring of information from existing protocols, the system reduces the risk of human error, ensures consistency across all generated forms, and significantly accelerates the time it takes to prepare an ICF draft for review.

3.  Data
3.1Overview

The "Setup" page bottom action bar includes a feature that allows users to initiate the generation of an Informed Consent Form (ICF). When a user triggers this action, the system begins a background process to create the document, allowing the user to continue their work without waiting for the file to finish generating.

3.2Step-by-Step Flow
1.Initiation: The user clicks the generate action on the Setup page.
2.Validation: The system checks the provided information to ensure it is complete and accurate.
3.Job Creation: The system creates a new "pending" task in the background to handle the document generation.
4.Confirmation: The system immediately sends a confirmation back to the user, providing a unique job ID that identifies this specific generation request.
5.Background Processing: The system works in the background to finalize the document, keeping the user interface responsive.
3.3Key Concepts
–ICF Generation: The automated process of creating an Informed Consent Form based on the specific protocol and template selected by the user.
–Background Processing: A method where the system performs complex tasks "behind the scenes," ensuring the user does not have to wait on a loading screen.
–Job ID: A unique reference number assigned to each generation request, which allows the system to track the progress of that specific document.
–Pending Status: The initial state of a request, indicating that the system has received the instruction and is preparing to process it.
3.4Business Value

This feature improves user productivity by removing the need to wait for document generation to complete before moving to the next task. By handling the process in the background, the application remains fast and responsive, providing a smoother experience for users managing complex protocol setups.
