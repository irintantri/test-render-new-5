1.  components
1.1Overview

The Comments & Approval feature provides a centralized workspace on the document review page to manage feedback and finalize document approval. It allows team members to discuss specific sections, track the status of feedback, and ensures that all necessary reviews and resolutions are completed before a document can be officially submitted for approval.

1.2Step-by-Step Flow
1.Adding Feedback: Users can add comments using the pinned composer at the bottom of the panel. When typing, they can associate the comment with a specific document section.
2.Managing Conversations: Comments are displayed in a threaded list. Each comment shows the author, timestamp, and the relevant section. Users can reply to existing comments to keep discussions organized.
3.Updating Status: Each comment has a status toggle (Open, Resolved, or Closed). Team members can update these statuses directly within the comment card to reflect the current state of the discussion.
4.Reviewer Actions: The Approval Gate tracks whether all assigned reviewers have completed their required actions. Reviewers can update their status via the interface.
5.Final Submission: The "Submit for Approval" button monitors the document's readiness. It remains disabled until two conditions are met: all comments are marked as "Resolved" or "Closed," and all reviewers have completed their actions. Once these criteria are satisfied, the button becomes active, allowing the user to submit the document.
1.3Key Concepts
–Comment Threading: A structured way to view original comments and their subsequent replies, keeping related feedback grouped together.
–Status Toggle: A control that allows users to move a comment from "Open" to "Resolved" or "Closed," which directly impacts the document's readiness for approval.
–Approval Gate: A validation check that prevents a document from being submitted until all feedback is addressed and all reviewers have provided their input.
–Section Association: The ability to link a comment to a specific part of the document, ensuring context is preserved for the reader.
1.4Business Value
–Quality Assurance: By requiring all comments to be resolved before submission, the system prevents documents from moving forward with outstanding issues or unanswered questions.
–Accountability: The Approval Gate ensures that every assigned reviewer has performed their duty, creating a clear audit trail for the document lifecycle.
–Efficiency: Centralizing communication and status tracking in one panel reduces the need for external emails or meetings, allowing teams to resolve feedback in real-time within the document context.
2.  Logic
2.1Overview

The Comment Actions feature provides a dedicated space on the document review page for team members to communicate, track feedback, and manage the approval process. It allows users to view threaded conversations, post new comments or replies, and update their individual review status, ensuring that all feedback is addressed before a document is submitted for final approval.

2.2Step-by-Step Flow
1.Loading Comments: When a user opens the document, the system automatically retrieves all existing comments and replies, displaying them in a threaded list within the right-hand panel.
2.Adding Feedback: Users can add new comments or reply to existing ones using the pinned composer at the bottom of the panel. Once submitted, the new entry is saved and immediately appears in the thread.
3.Managing Review Status: Within the approval area, reviewers can click an "Act" button to confirm their participation. The system updates their status to "acted" in real-time.
4.Approval Validation: The system continuously monitors two conditions: that all comments are marked as "Resolved" or "Closed," and that every reviewer has performed their "Act" action.
5.Submission: Once all comments are resolved and all reviewers have acted, the "Submit for Approval" button becomes active, allowing the user to finalize the document review.
2.3Key Concepts
–Threaded Comments: A structured view where replies are nested under their original parent comment, keeping conversations organized and easy to follow.
–Reviewer Status: A tracking mechanism that records whether a specific reviewer has completed their required actions on the document.
–Approval Gate: A safety check that prevents a document from being submitted until all feedback is addressed and all reviewers have signed off.
–Real-time Updates: The ability for the comment thread to refresh instantly when a new comment is added, without requiring the user to manually reload the page.
2.4Business Value

This feature streamlines the review cycle by centralizing communication and accountability. By enforcing an "Approval Gate," it ensures that no document is submitted prematurely, reducing the risk of overlooked feedback or incomplete reviews. The real-time nature of the comment thread fosters faster collaboration, allowing teams to resolve issues efficiently and move projects forward with confidence.

3.  Data
3.1Overview

The Comment Actions feature provides a dedicated space on the document review page for users to collaborate. It allows reviewers to post comments, reply to existing discussions, and track the resolution status of specific feedback. Additionally, the system automatically tracks when a reviewer has taken action on a document, ensuring clear visibility into the review progress.

3.2Step-by-Step Flow
1.Viewing Comments: When a user opens a document, the system automatically retrieves all existing comments and replies associated with that specific document and displays them in the right-hand panel.
2.Adding Feedback: A user can create a new comment or reply to an existing one. The system saves this input, assigns it an "open" status, and updates the view in real-time.
3.Managing Status: As discussions progress, users can update the status of a comment (e.g., marking an "open" issue as "resolved") to help the team track what still requires attention.
4.Tracking Reviewer Activity: Once a reviewer interacts with the document, the system updates their personal status to "acted," providing a clear indicator that they have participated in the review process.
3.3Key Concepts
–Comment Threading: The ability to group original comments with their subsequent replies, keeping related feedback organized.
–Comment Status: A label assigned to each comment (such as "open" or "resolved") that helps teams manage the lifecycle of feedback.
–Reviewer Activity Tracking: A system-level flag that records whether a specific reviewer has performed an action on the document, helping project leads monitor participation.
–Real-time Updates: The system’s ability to display new comments or status changes immediately without requiring the user to refresh the page.
3.4Business Value
–Improved Collaboration: By centralizing feedback in a dedicated panel, team members can discuss specific document sections directly, reducing the need for external communication tools.
–Enhanced Accountability: Tracking reviewer activity ensures that project managers can easily identify who has completed their review and who is still pending.
–Streamlined Workflow: The ability to mark comments as "resolved" allows teams to focus on outstanding issues, ensuring that no critical feedback is overlooked during the review cycle.
