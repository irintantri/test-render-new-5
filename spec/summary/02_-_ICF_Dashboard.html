1.  Frontend
1.1Overview

The Consent IQ Dashboard serves as the central command center for managing Informed Consent Forms (ICFs). It provides a high-level summary of your consent activity and a structured list of all protocols, allowing users to easily search, sort, and access specific documents for review or editing.

1.2Step-by-Step Flow
1.Dashboard Initialization: Upon loading, the system automatically retrieves and displays summary statistics, including the total number of consents, those currently in review, and those already approved.
2.Navigation: Users can initiate the creation of a new consent form by clicking the "Create New Consent" button in the header.
3.Searching: Users can type into the search bar to instantly filter the list of protocols by name or ICF details. Clearing the search box restores the full list.
4.Sorting: Users can click on any column header in the table to sort the data. Clicking a header toggles the order between ascending and descending; a visual indicator (▲/▼) shows the current sort status.
5.Managing Documents: Each protocol row provides action buttons:

* View: Opens a preview of the document.

* Open: Navigates to the editing interface for drafts or documents currently in review.

* Archived Items: Protocols marked as "Archived" are read-only and do not display action buttons.

1.3Key Concepts
–Consent IQ Dashboard: The main interface for tracking and managing the lifecycle of consent forms.
–Protocol Table: A dynamic list displaying key details such as protocol IDs, versions, current status, and last modification dates.
–Status Indicators: Visual badges that categorize each document (e.g., Draft, In Review, Approved) to help users quickly identify the progress of a protocol.
–Dynamic Search: A real-time filtering tool that updates the table view as you type to help you locate specific protocols or ICFs quickly.
–Sortable Columns: A feature that allows users to organize the table data by clicking headers, making it easier to find the most recently modified or specific versions of documents.
1.4Business Value

This dashboard streamlines the administrative workflow by consolidating all consent-related tasks into one view. By providing instant access to status metrics and intuitive search and sort capabilities, it reduces the time spent manually tracking documents. This ensures that teams can efficiently monitor the progress of consent forms, quickly identify items requiring attention, and maintain better oversight of the entire protocol lifecycle.

2.  Logic
2.1Overview

The ICF Dashboard serves as the central command center for managing consent forms. It provides users with a high-level summary of their workload while offering powerful tools to locate and organize specific protocols and their associated documents. The dashboard is designed to be responsive, allowing users to quickly filter through data and monitor the progress of consent forms through their lifecycle.

2.2Step-by-Step Flow
1.Dashboard Initialization: When the page loads, the system automatically retrieves summary statistics, including the total number of protocols and a breakdown of those currently "In Review" versus "Approved."
2.Data Retrieval: The system fetches the full list of protocols, pulling in relevant details such as version numbers, status, and associated file information.
3.Sorting: Users can click on column headers to organize the list. The system dynamically updates the view to sort data in either ascending or descending order based on the selected category.
4.Searching: As a user types into the search bar, the system instantly filters the list. It looks for matches across both protocol names and consent form names, narrowing down the results in real-time to help the user find exactly what they need.
2.3Key Concepts
–Protocol: The primary record representing a clinical study, which contains specific versions, status updates, and associated documentation.
–ICF (Informed Consent Form): The specific document or file linked to a protocol that is being tracked and managed within the system.
–Dashboard Statistics: A high-level snapshot provided at the top of the screen that gives immediate visibility into the volume and status of all active work.
–Dynamic Sorting: The ability to reorder the list by clicking headers, allowing users to prioritize information (e.g., by status or date).
–Instant Search: A responsive search feature that filters results as the user types, eliminating the need to press "enter" or wait for a page refresh.
2.4Business Value
–Improved Efficiency: By providing instant search and sorting, users spend less time hunting for documents and more time managing them.
–Enhanced Visibility: The dashboard statistics provide immediate insight into the current workload, helping teams identify bottlenecks (such as a high volume of forms "In Review") at a glance.
–Centralized Management: Consolidating protocol data and file information into one view ensures that users have a single source of truth, reducing the risk of errors or version confusion.
3.  Data
3.1Overview

The ICF Dashboard serves as the central command center for managing Informed Consent Forms (ICFs) across various research protocols. It provides users with a high-level summary of their current workload and a detailed, searchable list of all consent forms, allowing for efficient tracking and organization of documentation.

3.2Step-by-Step Flow
1.Dashboard Initialization: When you first open the dashboard, the system automatically calculates and displays summary statistics, including the total number of protocols and a breakdown of how many are currently "In Review" versus "Approved."
2.Data Retrieval: The system fetches the full list of protocols, displaying key details such as the protocol name, version, associated ICF name, current status, and the date of the last modification.
3.Searching: You can enter a specific protocol name or ICF name into the search bar. The system will filter the list in real-time to show only the items that match your criteria.
4.Sorting: You can organize the list by clicking on column headers (such as status or last modified date) to sort the information in either ascending or descending order, helping you prioritize your work.
3.3Key Concepts
–Protocol: A formal research study plan that serves as the primary container for all associated consent documentation.
–ICF (Informed Consent Form): The specific document used to obtain participant consent, which is tracked and managed within the context of its parent protocol.
–Dashboard Stats: A quick-reference summary that provides immediate visibility into the volume and progress of your consent forms.
–Filtering & Sorting: Tools that allow you to narrow down large lists of data and arrange them in a way that makes the most sense for your current task.
3.4Business Value

This feature eliminates the need to manually track consent forms across disparate systems. By providing a unified view, it reduces administrative burden, minimizes the risk of missing critical updates, and ensures that team members can quickly identify which protocols require immediate attention based on their current status.
