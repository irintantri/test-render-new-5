1.  Frontend
1.1Overview

The ICF Generation feature provides a transparent, real-time view of the document creation process. When a user initiates the generation of an Informed Consent Form (ICF), the system transitions to a dedicated dashboard that tracks progress, estimates the remaining time, and highlights specific milestones as they are completed. Once the document is fully generated, the system automatically redirects the user to the editor to review the final output.

1.2Step-by-Step Flow
1.Initiation: The user triggers the generation process, and the system begins monitoring the status of the request.
2.Real-Time Tracking: The dashboard displays a progress bar and a countdown timer (ETA) that updates automatically as the system works.
3.Milestone Visualization: The system moves through six distinct stages:

* Parsing protocol data

* Loading reference documents

* Applying regulatory templates

* Generating consent sections

* Running compliance checks

* Finalizing document

4.Status Updates: Each stage is visually marked as "In progress" (with an animated spinner), "Done" (with a green checkmark), or "Pending" (for future steps).
5.Completion: Once the final stage is reached and the progress hits 100%, the system automatically navigates the user to the document editor to view the completed ICF.
1.3Key Concepts
–Progress Tracking: A visual indicator showing the percentage of completion to keep the user informed of the system's activity.
–ETA Display: A dynamic countdown timer that estimates how much time is left until the document is ready, helping manage user expectations.
–Sequential Checkpoints: A list of specific tasks the AI performs, providing transparency into the "behind-the-scenes" work required to build the document.
–Auto-Navigation: A seamless transition that moves the user from the generation screen to the editor as soon as the file is ready, removing the need for manual interaction.
1.4Business Value

This feature significantly improves the user experience by eliminating the "black box" effect during document generation. By providing clear, step-by-step feedback and an estimated time of arrival, users feel more confident in the system's reliability. Furthermore, the automatic transition to the editor reduces friction, allowing users to move immediately from generation to review without unnecessary clicks or waiting.

2.  Logic
2.1Overview

The ICF Generation feature provides a transparent, real-time view of the AI document creation process. Instead of leaving the user waiting on a static screen, the system displays a progress bar and a list of six specific checkpoints. As the AI works, the interface updates dynamically to show exactly which stage of the generation is currently active, ensuring the user is kept informed until the document is ready for review.

2.2Step-by-Step Flow
1.Initialization: Once the generation process begins, the system establishes a live connection to monitor the AI's progress.
2.Real-time Updates: As the AI completes tasks, the system receives live updates. The progress bar advances, and the specific checkpoint currently being processed is highlighted on the screen.
3.Completion: Once the AI finishes all six steps, the system marks the process as complete.
4.Auto-Navigation: After a brief pause to allow the user to see the final status, the system automatically redirects the user to the editor screen, where they can review and refine the newly created document.
5.Error Handling: If the connection is interrupted or the generation fails, the system stops the process and displays an error message, allowing the user to address the issue.
2.3Key Concepts
–Live Progress Tracking: A visual indicator that keeps the user updated on the status of the AI generation in real-time.
–Checkpoints: A set of six distinct milestones that break down the complex generation process into understandable stages.
–Auto-Navigation: A seamless transition that moves the user from the generation screen to the editing workspace as soon as the document is ready.
–Connection Monitoring: A background process that ensures the user is alerted immediately if the generation encounters a technical issue or connection loss.
2.4Business Value

This feature improves the user experience by removing the uncertainty often associated with AI-driven tasks. By providing clear, step-by-step visibility, users feel more confident in the system's reliability. Furthermore, the automatic transition to the editor reduces friction, allowing users to move directly from document creation to the refinement phase without unnecessary manual clicks.
